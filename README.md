# 📌 Selected Research Projects

## 🦷 Dental Implant Detection, Six-Keypoint Localization & Bone Loss Assessment

A multi-stage deep learning framework for quantitative analysis of dental implants in panoramic radiographs.

**Main components:**

- Dental implant detection using **YOLOv11m**
- Six anatomical keypoint localization
- Comparison of **HRNet-W32** and **ViTPose**
- Bone-region and peri-implant bone-loss analysis
- Quantitative keypoint and geometric evaluation

🔗 [View Repository](https://github.com/najeebullahr/dental-implant-keypoint-localization)

---

## 🎗️ Breast Cancer Classification Using Deep Learning & Radiomics

A medical imaging framework investigating CNN-based representations, handcrafted radiomics features, and multimodal fusion for mammography classification.

**Main components:**

- ResNet18
- DenseNet121
- GoogLeNet
- SqueezeNet
- PyRadiomics feature extraction
- XGBoost classification
- Deep learning–radiomics fusion
- Grad-CAM++
- Model calibration
- Decision Curve Analysis

🔗 [View Repository](https://github.com/najeebullahr/breast-cancer-radiomics-deep-learning)

## 🚑 Multilingual Emergency-Call Triage Classification & Summarization

A multilingual medical NLP system developed for the **NTCIR-19 MedNLP-CALL** research task.

The project addresses two major tasks:

### Triage Classification

Prediction of emergency severity from multilingual emergency-call conversations.

### Emergency-Call Summarization

Generation of concise summaries containing the most important information from emergency conversations.

**Main components:**

- XLM-RoBERTa
- Multilingual and language-specific transformer encoders
- Case-grouped cross-validation
- Class-weighted learning
- Generative data augmentation
- Semantic filtering
- Triage-consistency verification
- Soft-voting ensembles
- Safety-aware under-triage evaluation
- T5-based summarization
- LLM-based summarization
- Few-shot prompting
- ROUGE evaluation

🔗 [View Repository](https://github.com/najeebullahr/multilingual-emergency-triage-nlp)
